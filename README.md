# Система видеонаблюдения АЗС с инкрементальным дообучением

Веб-приложение для видеонаблюдения на АЗС: детекция объектов (YOLOv8 + ByteTrack),
зоны срабатывания, пользовательские классы и правила тревог, отправка тревог
по email и Telegram, инкрементальное дообучение модели на размеченных оператором
кадрах.

## Возможности

- Видеопоток с веб-камеры, видеофайла или RTSP/IP-камеры с горячей сменой источника.
- Детекция объектов с настраиваемым набором классов и порогом уверенности.
- Зоны срабатывания: рисование на видео, контекстная настройка по клику на зоне,
  импорт/экспорт зон в файлы `zones/zoneX.json`.
- Пользовательские классы объектов (например, «сигарета», «огонь», «дым»).
- Правила тревог («класс X в зоне Y»), привязка правил к зонам.
- Отправка тревог по email (сразу, после N срабатываний или с задержкой) и в Telegram.
- Инкрементальное дообучение: автоматический сбор трудных примеров, псевдо-разметка,
  ручная разметка кадров без автоматической детекции, дообучение с откатом при деградации.
- Журнал событий с фильтрами и отчётностью по зонам.

## Требования

- Python 3.10–3.11 (рекомендуется; пакеты `torch`/`ultralytics` на момент поставки
  не поддерживают Python 3.14).
- Зависимости из `requirements.txt`.

## Установка

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

Модель `model/yolov8n.pt` поставляется вместе с проектом. При первом запуске
`ultralytics` может дозагрузить недостающие веса автоматически.

## Запуск

```bash
python main_web.py
```

Интерфейс: http://localhost:8000

## Структура проекта

```
la_diploma/
├── main_web.py            # FastAPI-сервер и все API-маршруты
├── config.py              # загрузка/сохранение настроек (data/settings.json)
├── cloud_server.py        # отдельный облачный сервер для синхронизации событий
├── requirements.txt
├── core/                  # бэкенд-модули
│   ├── detector.py            # YOLOv8 + ByteTrack, реестр классов
│   ├── classes.py             # пользовательские классы (config/classes.json)
│   ├── rules.py               # правила тревог (config/rules.json)
│   ├── zones.py               # логика зон срабатывания
│   ├── zone_store.py          # хранение зон в zones/zoneX.json
│   ├── email_notify.py        # отправка тревог по email (SMTP)
│   ├── telegram_notify.py     # отправка тревог в Telegram
│   ├── incremental_trainer.py # сбор данных и дообучение модели
│   ├── anomaly_detector.py    # эвристики аномалий
│   ├── rtsp_manager.py        # захват видео с восстановлением и пейсингом
│   ├── video_buffer.py        # буфер для видеофрагментов тревог
│   ├── cloud_sync.py          # фоновая синхронизация с облаком
│   └── database.py            # SQLite-журнал событий
├── templates/             # HTML-страницы
│   ├── index.html             # Монитор (видео, зоны, метрики)
│   ├── events.html            # Журнал событий
│   ├── retrain.html           # Дообучение (предложения, ручная разметка)
│   ├── manage.html            # Управление: классы, правила, отправка тревог
│   └── settings.html          # Настройки
├── model/                 # веса модели
├── config/                # классы и правила (создаётся при работе)
├── zones/                 # файлы зон zoneX.json (создаётся при работе)
└── data/                  # БД событий, настройки, данные дообучения
```

## Навигация

Верхнее меню одинаково на всех страницах:
Монитор · События · Дообучение · Управление · Настройки.
Клик по логотипу всегда возвращает на Монитор.

## Безопасность

В поставке учётные данные (пароль SMTP, токен Telegram, API-ключ облака) заменены
на пустые значения или заглушки. Заполните их через интерфейс настроек.
